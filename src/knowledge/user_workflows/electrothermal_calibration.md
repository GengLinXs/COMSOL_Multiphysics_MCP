# 电热标定与独立 MPh 运行经验

## 唤起条件

- **运行兼容性**：实际使用独立 MPh/JPype，创建 HeatTransfer 时出现 ASHRAE/SQLite/SLF4JLoggerFactory 初始化异常才参考相应诊断。不能把所有物理场初始化失败都归因于此。
- **后处理/API**：读取瞬态/参数扫描末端结果、解后新增积分算子、导出模型或参数保护审计时，启用对应条目；不依赖特定论文。
- **电热标定专用**：任务明确要求已有电池 P2D/热模型的参数辨识、温度内阻反馈或恒功率耦合时启用。其他模型不采用此处的物理简化、算法或负载表达式。
- **非局部雅可比**：存在实时非局部耦合并已定位其稠密雅可比导致装配内存不足时，才评估 nojac；不作为默认设置。

## 独立 MPh 兼容性与连接

1. 曾在 COMSOL 6.4/MPh 1.4 中观察到：plugins 通配符将 `org.osgi.slf4j.*` 绑定器加载到非 OSGi JVM，HeatTransfer 的 ASHRAE SQLite 初始化在 SLF4JLoggerFactory 中失败。最小 PDE 成功不能排除此类接口专用问题；必须创建目标物理场验证。
2. MCP 在实际 standalone plugins JVM 启动前只排除此绑定器，保留 SLF4J API、SQLite 与其他 COMSOL JAR，不修改安装目录。远程 apiplugins 和已有 JVM 不作此更改。环境变量 `COMSOL_MCP_STANDALONE_SLF4J=off` 可禁用；类路径在 JVM 启动后不可修复，修改后使用新进程。
3. JVM 能启动不代表可以建模；用户 `.comsol` 恢复目录无写权限可能直到创建模型才报错。明确区分权限、许可、接口与类路径错误，遵守客户端的权限流程。
4. GitHub 源码已更新、Codex 配置存在、当前会话工具已加载是三种不同状态。新安装/更新后按客户端能力重连 MCP 或新建会话；缺少当前工具不等于未推送代码。报告使用的是 MCP 还是直接 MPh，不能混称。

## 结果、求解器与模型交付

5. 明确研究、解和数据集；瞬态末端与参数扫描末端分别选择，禁止默取第一时间点。MCP `inner='last'/'end'`、`outer='last'/'end'` 先解析为实际数值索引，不能原样写入仅支持常量的 Java `solnum` 属性。MATLAB 的参数语义不能机械移植给 Java。
6. `results_global_evaluate` 遇到多值应报错并要求选择或改用场求值，禁止把多时间点/空间值的首项冒充最终标量。
7. 解后添加积分等算子导致“未知函数或算子”时，核实所属组件与数据集，显式使用 `solution_update` 更新指定解。它仅更新已有解元数据，不能代替修改方程/参数/网格后的重算；不得自动刷新全部历史解。
8. 遍历实际 physics feature/property group 后再查合法属性；Physics 根不保证存在 `properties()`。完整保护审计包括参数、材料及其函数、组件/全局函数、物理树和允许修改项，不以少量标量快照冒充完整审计。
9. 二进制快照必须使用 `.mph`；Java 源码明确使用 `format='Java'`。扩展名不能改变直接 Java `save(path)` 的默认语义。MCP 拒绝显式格式与扩展名冲突。
10. 对交付模型从磁盘重载，核实最终解时段、数值有限、数据集、研究入口及参数/场一致；原模型校验和保持不变。若只检查了重载而未独立重算，明确说明。清楚标识热模型检查点与最终耦合模型，不对被替换热源直接运行旧研究。

## 电池电热标定专用原则

11. 冻结用户指定的已有电化学标定，变更单独记录。温度增量修正在参考温度严格归零，使用实际定义的核心温度反馈，区分表面热电偶、体积平均与节点平均。
12. 确认电流方向和功率量纲：把单位长度/面积/体积热源正确转成单芯功率，额外 `I²ΔR` 只计一次，核对新研究激活的热耦合，避免与已有热源重复。参考温度的原始偏差保留并报告。
13. 当接触阻抗实现会对零增量取倒数时，不把参考温度为零的 ΔR 直接放入该节点；可采用符号一致的外部代数串联电压修正，保持原电极/膜阻抗。选择方案须按实际电路和变量定义验证，不要求所有模型都改用外部修正。
14. 恒功率电流直接引用包含自身的端电压会循环依赖。按实际功率方程建立代数约束或有物理依据的解析支路；采用低电流根前核对符号、判别式、零修正极限及电压截止，不能盲用通用公式。
15. 非局部平均温度/积分热源导致雅可比稠密、装配内存不足时，先定位。可仅用 `nojac` 省略非局部导数，保留残差中实时温度与热源耦合；记录线性化变更并验证收敛/能量，不宣称这等于冻结场或已证明完整 Newton 的等价性。
16. 脉冲边缘输出加密或使用求解器积分验证 `I²` 和能量收支；粗输出插值会放大残差，不直接据此认定能量方程错误。收敛与能量误差阈值由当前任务指定。
17. 数据解析核对实际单元格/表头和行列数；错误 XLSX dimension 声明可能漏列。脉冲 DC 指标明确使用哪个静置基准、持续时间及取点，不混用加载首点。
18. 按电芯/实验组划分训练验证，控制 SOC/温度覆盖；缺实测温度、环境箱历程不明或文件名标签矛盾时记录排除原因，不将名义温度当实测边界，不把缺数据工况说成已验证。
19. 单表面温度一般不足以唯一辨识全部导热、接触、对流及传感器响应。区分等效参数与本征材料属性；降阶模型仅提初值，实际 COMSOL 验证另行报告；单独热模型与完整电热模型的误差不得混报。

这些是一次实际建模中提炼的运行与方法经验，不携带其私有实验数据、模型、拟合参数或研究结论。历史修复成功不能保证其他版本、物理场和许可证配置都兼容。
