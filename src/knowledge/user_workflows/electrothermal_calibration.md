# 电热标定与独立 MPh 运行经验

## 唤起条件

- **运行兼容性**：实际使用独立 MPh/JPype，创建 HeatTransfer 时出现 ASHRAE/SQLite/SLF4JLoggerFactory 初始化异常才参考相应诊断。不能把所有物理场初始化失败都归因于此。
- **后处理/API**：读取瞬态/参数扫描末端结果、解后新增积分算子、导出模型或参数保护审计时，启用对应条目；不依赖特定论文。
- **电热标定专用**：任务明确要求已有电池 P2D/热模型的参数辨识、温度内阻反馈或恒功率耦合时启用。其他模型不采用此处的物理简化、算法或负载表达式。
- **非局部雅可比**：存在实时非局部耦合并已定位其稠密雅可比导致装配内存不足时，才评估 nojac；不作为默认设置。
- **温度输入与组件降阶**：改变温度却没有预期响应，或用户明确只求解部分组件时，启用下面的输入追踪及降阶检查；不自动关闭用户未授权停用的组件。
- **脉冲与结果树维护**：负载开关附近对容差敏感，或清理已有研究、求解器、数据集时，启用实际步长和依赖检查；不为所有瞬态强制严格步进或统一毫秒步长。

## 独立 MPh 兼容性与连接

1. 曾在 COMSOL 6.4/MPh 1.4 中观察到：plugins 通配符将 `org.osgi.slf4j.*` 绑定器加载到非 OSGi JVM，HeatTransfer 的 ASHRAE SQLite 初始化在 SLF4JLoggerFactory 中失败。最小 PDE 成功不能排除此类接口专用问题；必须创建目标物理场验证。
2. MCP 在实际 standalone plugins JVM 启动前只排除此绑定器，保留 SLF4J API、SQLite 与其他 COMSOL JAR，不修改安装目录。远程 apiplugins 和已有 JVM 不作此更改。环境变量 `COMSOL_MCP_STANDALONE_SLF4J=off` 可禁用；类路径在 JVM 启动后不可修复，修改后使用新进程。
3. JVM 能启动不代表可以建模；用户 `.comsol` 恢复目录无写权限可能直到创建模型才报错。明确区分权限、许可、接口与类路径错误，遵守客户端的权限流程。
4. GitHub 源码已更新、Codex 配置存在、当前会话工具已加载是三种不同状态。新安装/更新后按客户端能力重连 MCP 或新建会话；缺少当前工具不等于未推送代码。报告使用的是 MCP 还是直接 MPh，不能混称。

## 结果、求解器与模型交付

5. 明确研究、解和数据集；瞬态末端与参数扫描末端分别选择，禁止默取第一时间点。MCP `inner='last'/'end'`、`outer='last'/'end'` 先解析为实际数值索引，不能原样写入仅支持常量的 Java `solnum` 属性。MATLAB 的参数语义不能机械移植给 Java。
6. `results_global_evaluate` 遇到多值应报错并要求选择或改用场求值，禁止把多时间点/空间值的首项冒充最终标量。
7. 解后添加积分等算子导致“未知函数或算子”时，核实所属组件与数据集，显式使用 `solution_update` 更新指定解。它仅更新已有解元数据，不能代替修改方程/参数/网格后的重算；不得自动刷新全部历史解。
8. 遍历实际 physics feature/property group 后再查合法属性；Physics 根不保证存在 `properties()`。完整保护审计包括参数、材料及其函数、组件/全局函数、物理树和允许修改项，不以少量标量快照冒充完整审计。
9. 二进制快照必须使用 `.mph`；Java 源码明确使用 `format='Java'`。扩展名不能改变直接 Java `save(path)` 的默认语义。MCP 拒绝显式格式与扩展名冲突。
10. 对交付模型从磁盘重载，核实最终解时段、数值有限、数据集、研究入口及参数/场一致；原模型校验和保持不变。若只检查了重载而未独立重算，明确说明。清楚标识热模型检查点与最终耦合模型，不对被替换热源直接运行旧研究。

## 电池电热标定专用原则

11. 冻结用户指定的已有电化学标定，变更单独记录。温度增量修正在参考温度严格归零，使用实际定义的核心温度反馈，区分表面热电偶、体积平均与节点平均。
12. 确认电流方向和功率量纲：把单位长度/面积/体积热源正确转成单芯功率，额外 `I²ΔR` 只计一次，核对新研究激活的热耦合，避免与已有热源重复。参考温度的原始偏差保留并报告。
13. 当接触阻抗实现会对零增量取倒数时，不把参考温度为零的 ΔR 直接放入该节点；可采用符号一致的外部代数串联电压修正，保持原电极/膜阻抗。选择方案须按实际电路和变量定义验证，不要求所有模型都改用外部修正。
14. 恒功率电流直接引用包含自身的端电压会循环依赖。按实际功率方程建立代数约束或有物理依据的解析支路；采用低电流根前核对符号、判别式、零修正极限及电压截止，不能盲用通用公式。
15. 非局部平均温度/积分热源导致雅可比稠密、装配内存不足时，先定位。可仅用 `nojac` 省略非局部导数，保留残差中实时温度与热源耦合；记录线性化变更并验证收敛/能量，不宣称这等于冻结场或已证明完整 Newton 的等价性。
16. 脉冲边缘输出加密或使用求解器积分验证 `I²` 和能量收支；粗输出插值会放大残差，不直接据此认定能量方程错误。收敛与能量误差阈值由当前任务指定。
17. 数据解析核对实际单元格/表头和行列数；错误 XLSX dimension 声明可能漏列。脉冲 DC 指标明确使用哪个静置基准、持续时间及取点，不混用加载首点。
18. 按电芯/实验组划分训练验证，控制 SOC/温度覆盖；缺实测温度、环境箱历程不明或文件名标签矛盾时记录排除原因，不将名义温度当实测边界，不把缺数据工况说成已验证。
19. 单表面温度一般不足以唯一辨识全部导热、接触、对流及传感器响应。区分等效参数与本征材料属性；降阶模型仅提初值，实际 COMSOL 验证另行报告；单独热模型与完整电热模型的误差不得混报。

## 温度输入追踪与一维电热降阶

20. 改变全局温度参数但曲线完全重合时，先沿实际方程追踪温度来源。关闭传热求解不等于关闭多物理场耦合；仍激活的电化学热耦合可能继续供应未求解的旧温度场。逐项核对研究的物理场/组件激活、耦合激活、未求解变量来源，并实际求值反应、颗粒扩散及材料模型的温度输入。只看全局参数或属性字符串不能证明温度已进入方程。
21. `editModelInputs` 一类开关可能同时控制温度、浓度、电势等多项输入。不能为修改温度而盲目开启它：先检查节点的全部模型输入及合法来源，再修改所需项，求解后验证输入和输出。COMSOL 6.4 的一个 P2D 实例中，保留正确热耦合并关闭手动整体覆盖才能避免其他输入被重置；这不是所有接口的固定配置。
22. 熵系数 `dEeqdT` 与动力学/输运温度依赖分别核对。保留并检查实际 OCP、熵系数插值表、单位、SOC/化学计量变量及参考温度；不能用任意放大熵系数补偿缺失的低温极化。材料原本使用常数扩散、导电率或交换电流时，正确传入温度也不必然产生完整温度响应。
23. 用户授权只求解一维电热组件时，显式关闭其他组件及其传热物理场；电流分布初始化和瞬态步骤分别核实。将整芯热容与外部散热热导映射至一维计算体积和边界，核对单位与总量，停用被替代的散热项。降阶温度代表等效电芯温度，不能作为被停用轴对称模型的局部表面探针预测；未经验证的导热系数、对流比例和映射公式不能跨项目复用。
24. 区分内活性面积上的面比膜阻抗和整芯串联电阻。先核对界面电流密度、面积基准、单位及实际压降，再选择实现位置。电化学热耦合可能已经计入接触边界的焦耳热，不能仅凭热源节点名称认定遗漏；通过已求解功率及热量收支验证，避免重复添加同一 `I²R`。
25. 额外的整芯 OCV 修正、温度/SOC 相关极化状态及耗散必须写入求解模型，并用于恒功率约束、截止和热源的同一端电压定义。它们通常是有效参数，不是唯一辨识的单电极 OCP、扩散或真实接触阻抗。优先检验同类负载的组间差值；容量轴拉伸、绘图电压平移不能作为物理校准证据。

## 脉冲实际步长与数值复核

26. 增加导出时间点不保证求解器经过这些时间点。自由时间步可能跨过负载切换区，再把代数端电压插值成缓变曲线；总体 RMS 很小仍可能伴随较大瞬时误差。比较同一初态的容差/实际步长结果，检查实际电流、端电压、开关时间及其两侧样本，不能只检查全窗口平均值。
27. 确认切换区被跨越后，可按当前版本的合法属性采用严格输出步进、局部最大实际步长或适当事件；步长取决于开关过渡宽度和所需精度。COMSOL 6.4 的 BDF 实例使用 `tstepsbdf='strict'`、`maxstepconstraintbdf='expr'` 和有时间单位的 `maxstepexpressionbdf`，设置在实际瞬态求解器节点；节点标签和属性允许值须现场查询，不能套用到不存在的节点。每次研究生成/更新求解序列后还要核对设置确实生效。
28. 数值复核包括开关区，不通过删除瞬态点或放宽阈值掩盖失败。修复后重新求解受影响工况、归档旧曲线并更新指标、源数据和图件。加载段、恢复段、静置基准和定时 DC 电阻分别报告，不能只凭某一个电阻指标宣布完整动态过程通过。只有确认未受影响的其他工况才可复用。

## 模型交付与 API 依赖补充

29. 清理旧研究/求解器时，保留当前研究依赖的初始化和存储解，不只保留最终瞬态解。删除父数据集可能自动删除衍生数据集；遍历旧标签快照时，在每次取对象或删除前重新检查当前标签是否存在。不要用忽略全部异常的方式掩盖当前数据集丢失。清理完成后从磁盘重载并独立运行交付研究，核对结果及研究入口。
30. Java 字符串矩阵不要直接当成 NumPy 浮点矩阵。先逐行逐元素转换，例如 `[[float(str(v)) for v in row] for row in table]`，再检查矩阵形状、单位、数值有限及插值自变量单调性。跨 Python/Java 的标签集合比较可先显式转换为 Python 字符串，避免依赖隐式转换行为。
31. 参数保护审计须读取实际函数表，而非只比较函数名和少数标量。可从 Java API 或当前 MPH 中的完整序列化表核对 OCP/熵系数的值与单位；轻量树摘要可能不包含表数据。文件结构属于版本相关实现，使用 MPH 内部 XML/JSON 时记录版本并核对解析覆盖范围，不把缺字段视为“未改变”。
32. 独立脉冲初态若由实验静置电压反演 SOC，记录其先验、约束和平台区不适定性。剩余初始极化只有作为可松弛模型状态才具有明确含义，不能作制图偏移；静置电压匹配本身不是独立 OCV 验证。实验记录编号不自动等同独立物理电芯，开发中看过留出误差也不能宣称盲法或外部验证。
33. 区分完整放电工况、若干给定初态的代表 DC 窗口和完整连续协议重放。名义温度与辅助温度通道矛盾、缺热记录或空目标时，明确记录边界不确定、未通过项和跳过原因。报告主体区及完整共同有效范围的电压误差，不能只挑选主体区掩盖末段或组间差距。

以上为实际建模中提炼的运行与方法经验，不携带私有实验数据、模型、拟合参数或研究结论。历史修复成功不能保证其他版本、物理场和许可证配置都兼容。
